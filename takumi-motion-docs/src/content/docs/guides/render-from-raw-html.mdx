The engine accepts raw HTML as a first-class source. Use this path when the animation already exists as markup — a design system snippet, a generated template, a no-JS pipeline — and you need the same deterministic outputs the React path produces.

## Render an HTML string

```ts
import { renderHtmlAnimation } from "takumi-motion";

const report = await renderHtmlAnimation({
  html: `<div id="badge"><h1>ship it</h1></div>`,
  css: `
    #badge { display: flex; align-items: center; height: 200px; }
    h1 { opacity: 0; animation: rise 1.2s ease-out forwards; }
    @keyframes rise { from { opacity: 0; transform: translateY(-24px); } to { opacity: 1; } }
  `,
  frames: 30,
  fps: 20,
  width: 850,
  height: 200,
  outDir: "./out",
});
```

`renderHtmlAnimation` extracts the `<body>` from full documents (or takes a fragment), hoists `<style>` blocks, samples `frames` deterministic poses of the CSS animations, and encodes the preset formats. The report carries `cssEntries`, `styleBlocksHoisted`, `files`, `posters`, `fonts`, and budget fields.

## Use the CLI for files

The `render` command accepts `.html` and `.htm` files directly:

```sh
npx takumi-motion render badge.html --css badge.css --font-file Brand.ttf --frames 40 --out ./out
```

| Flag | Purpose |
| --- | --- |
| `--css <file>` | Attach an external stylesheet |
| `--font-file <path>` | Register a local TTF/OTF (repeatable; family defaults to the file stem) |
| `--frames <n>` | Frame count for the HTML path (default 30) |
| `--width` / `--height` / `--dpr` | Surface overrides |
| `--format gif,webp,apng` | Output formats |
| `--budget <bytes>` | Byte budget with exit code 2 on failure |

## Keep determinism intact

- Avoid JavaScript in the HTML — the engine renders markup and CSS, not scripts.
- Font bytes belong in the build: vendor TTF/OTF files locally (`--font-file`) instead of Google Fonts URLs. Remote fonts trip the `TM_FONT_NETWORK` lint because byte-determinism holds only while the remote bytes do.
- WOFF/WOFF2 files are rejected — convert to TTF or OTF first.

## Stills from HTML

`renderStill` accepts the same source trio — react banner, html, or declarative node+timeline:

```ts
import { renderStill } from "takumi-motion";

const still = await renderStill({ html: fragment, css, width: 1200, height: 630 });
console.log(still.png.length); // PNG bytes
```
