Takumi Motion compiles animation timelines ahead of time, captures frames deterministically, and delegates rasterization to a Rust backend. No headless browser, no layout thrashing, no nondeterministic replays — the same input produces the same bytes, every time.

## Why Takumi Motion

- **Deterministic by construction** — `Math.random` is frame-seeded, engine time is integer milliseconds, and every frame is a pure function of `(frame, props)`. Outputs are byte-identical across runs, worker counts, and machines.
- **Rust-fast rendering** — the takumi engine rasterizes CSS-style layouts in native code. The v1.0 *Velocity* pass lifted the hot path by a geometric mean of **1.71×** across 13 benchmarks.
- **Author in React** — banners are ordinary React trees with `<Scene>` and `<Layer>` primitives, Motion-compatible springs and easings, and frame-driven hooks.
- **Quality tooling built in** — a coded authoring lint (`TM_*`), per-frame X-ray attribution, extent auditing, and loop-seam verification ride along with every render report.
